# عسكر المعاني

لعبة تعليمية عربية مستوحاة من "عسكر وحرامية". يطارد اللاعب المعاني المختبئة داخل الجمل العربية، ويختار المعنى الصحيح للكلمة حسب السياق والصيغة والدلالة.

## الفكرة

بدل مطاردة أشخاص، يطارد اللاعب "المعنى" داخل جملة عربية. تظهر كلمة مستهدفة داخل الجملة، ثم تعرض اللعبة عدة بطاقات تمثل معاني محتملة في أماكن مختلفة على الخريطة مثل السوق، المدرسة، المكتبة، المحكمة، الصحراء، والميناء.

## الميزات

- واجهة عربية كاملة باتجاه RTL.
- خريطة لعب تفاعلية مبنية باستخدام Phaser.
- أكثر من 50 تحديًا عربيًا متدرج الصعوبة.
- نظام نقاط وسلاسل ومضاعفات.
- تلميحات محدودة باسم "بلاغ من العسكر".
- شارات إنجاز مثل محقق المعاني وصائد السياق وفارس الصرف.
- لوحة صدارة محلية تحفظ النتائج في المتصفح.
- شاشات البداية، التعليمات، الإعدادات، التحميل، اللعب، الفوز، والصدارة.
- نشر جاهز عبر GitHub Pages.

## التشغيل محليًا

افتح الملف التالي مباشرة في المتصفح:

```text
index.html
```

لا يحتاج المشروع إلى تثبيت حزم أو تشغيل خادم تطوير.

ملاحظة: تستخدم اللعبة Phaser من CDN، لذلك تحتاج اتصالًا بالإنترنت لعرض خريطة Phaser المتحركة عند التشغيل المحلي.

## النشر على GitHub Pages

يوجد workflow جاهز في:

```text
.github/workflows/deploy-pages.yml
```

يتم النشر تلقائيًا عند الدفع إلى فرع `main`، ويمكن تشغيله يدويًا من تبويب Actions في GitHub.

في إعدادات المستودع على GitHub، اجعل Pages source هو:

```text
GitHub Actions
```

## تطوير المحتوى

توجد بيانات التحديات داخل `app.js` في مصفوفة `CHALLENGES`. يمكن إضافة تحديات جديدة بنفس البنية:

```js
{
  word: "عين",
  sentence: "شرب المسافر من عين الماء.",
  skill: "السياق الدلالي",
  difficulty: 1,
  root: "ع ي ن",
  part: "اسم",
  meaningType: "حرفية",
  correctMeaning: "نبع الماء",
  choices: ["عضو البصر", "الجاسوس", "نبع الماء", "الشخص نفسه"],
  feedback: "السياق يشير إلى الماء، لذلك المقصود هو النبع.",
  hint: "ابحث عن قرينة الماء والشرب.",
  district: "desert"
}
```

قيمة `district` تحدد مكان المعنى الصحيح على الخريطة. القيم المتاحة:

```text
market, school, library, court, desert, port
```
